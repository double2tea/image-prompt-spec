# image-prompt-spec

Still-image generation and edit briefs for Banana, Seedream, GPT Image, and Qwen.

Distilled from [OSideMedia/higgsfield-ai-prompt-skill](https://github.com/OSideMedia/higgsfield-ai-prompt-skill) (MIT). Cinema Studio, Soul, credits, and CLI bindings are not in this repo.

The full upstream fork, with this skill on branch `image-prompt-spec`, is [double2tea/higgsfield-ai-prompt-skill](https://github.com/double2tea/higgsfield-ai-prompt-skill/tree/image-prompt-spec).

## Install

```bash
git clone https://github.com/double2tea/image-prompt-spec.git ~/.claude/skills/image-prompt-spec
```

## References

| File | Loaded when |

| SKILL.md | always, on trigger |
| references/models.md | a model is named or compared |
